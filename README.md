# Virtual Tier Racing

Tier-1-Ligaportal für Mitglieder des Discord-Servers. Die Anmeldung prüft die Servermitgliedschaft; eine besondere Rolle ist für das Ansehen der Liga-Inhalte nicht nötig. Gastzugang ist deaktiviert. Teamchef- und Admin-Funktionen benötigen weiter die passenden Berechtigungen.

[Website](https://juligg1506.github.io/f1-auction/) · [Zugriff, technische Grenzen und Tests](docs/SERVERZUGANG.md) · [Startnummern](docs/STARTNUMMERN.md)

Ältere Dokumentation zum öffentlichen Gastzugang ist durch SERVERZUGANG.md abgelöst. Die statischen GitHub-Pages-Dateien und das Repository bleiben öffentlich; geschützt sind Liga-Daten und Funktionen der API.
