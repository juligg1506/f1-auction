# Virtual Tier Racing

Tier-1-Ligaportal mit Discord-Anmeldung und Gastzugang. Gäste können Kalender, veröffentlichte Ergebnisse/Wertungen, Teams, Liga und Livestream ansehen. Persönliche Fahrerbereiche, Auktionen und Verwaltung benötigen die passende Anmeldung und Berechtigung.
